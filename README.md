# Expense Tracker

A command-line expense tracker written in Python. It lets me record everyday expenses, review saved entries, check spending totals, and organize expenses by category.

The data is stored locally in a JSON file, so it remains available when the program is run again.

## Features

- Add an expense with a title, amount, and category
- View all saved expenses, including their dates
- Calculate total spending
- Filter expenses by category
- List available categories without duplicates
- Delete an expense by its ID
- Validate user input and handle common file errors
- Save and load data using JSON

## Requirements

- Python 3

No third-party packages are required.

## Run the project

Open a terminal in the project directory and run:

```bash
python3 main.py
```

The program creates `expenses.json` when the first expense is saved.

## Data format

Each expense is stored as a JSON object with an ID, title, amount, category, and date.

```json
{
    "id": 1,
    "title": "Groceries",
    "amount": 450000,
    "category": "Food",
    "date": "2026-10-11"
}
```

The date is set automatically when an expense is added.

## Project structure

```text
expense-tracker/
├── main.py
├── README.md
├── .gitignore
└── expenses.json
```

`expenses.json` is generated by the program and does not need to be created manually.

## What I practiced

This project brings together Python fundamentals such as functions, loops, conditionals, lists, dictionaries, exception handling, file operations, JSON, `pathlib`, and set operations.

## Notes

This is a local command-line application intended for learning and personal use. It does not connect to a bank account or sync data between devices.
